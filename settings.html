订阅到期提醒

两种类型：按月续费（每月 N 日续费，自动算到下一个续费日）或固定日期到期（如限时权益，YYYY-MM-DD，到期后显示已到期）。下方每个已有订阅（含内置的 即梦 / Running Hub / 豆包免费 / WorkBuddy 积分）都可以直接编辑：改名称、切换类型、改续费日或到期日、改颜色、启用/停用、删除——即梦和 Running Hub 的续费日、豆包和 WorkBuddy 的到期日都可以按实际情况改，改完自动保存。

API 订阅额度

内置常用 API 平台模板（名称 + API 地址），下拉选择后输入 API Key 即可自动查询余额/订阅额度。支持一键查询：硅基流动、MiniMax（mimo）、DeepSeek；智谱 / 月之暗面 / 火山引擎 / 阿里云百炼 / 腾讯云无 API Key 直查余额接口，可填「手动余额」登记数值参与显示。新增的 API 条目会在小组件订阅页之后的新页中轮播。

页面轮播与到期提醒
